# 设计说明

## 气质

「此记」不是效率工具，也不是社交产品。它更像一本放在桌角的纸本：  
翻开、落笔、合上。界面不主动索取注意力。

三个词：**安静、温润、有分寸**。

## 色彩

| Token | Light | Dark | 用途 |
| --- | --- | --- | --- |
| paper | `#F4EFE4` | `#161411` | 窗口底色，宣纸 |
| surface | `#FBF7EE` | `#1D1B17` | 纸张 / 卡片 |
| surfaceAlt | `#EDE5D6` | `#24211C` | 次级面板 / 悬停 |
| ink | `#211E19` | `#EDE6D8` | 正文墨色 |
| inkSoft | `#575149` | `#B7AFA0` | 次级文字 |
| inkMuted | `#8D8576` | `#7E776B` | 辅助信息 |
| line | `#E3DAC8` | `#322E27` | 发丝线 |
| accent | `#A84637` | `#D07E6F` | 朱砂，单一强调色 |

规则：

- 一屏只允许一个高饱和色（朱砂）；其余颜色都从纸与墨里取得。
- 强调色只用于：当前选中、花字、保存状态、少量图标；不大面积铺。
- 卡片阴影极浅（light 约 5% 不透明度），靠边框和留白区分层级。
- 纸张颗粒是 5% 左右的噪点，只在大面积背景出现。

## 排版

- UI 使用思源黑体（Noto Sans SC）；标题和「此记」字标使用霞鹜文楷。
- 正文默认 17px / 1.9 行距，页宽默认 720px；行距与字号可调。
- 标题字距收紧（-0.2 到 -1.2），正文保持 0.15 的轻微字距。
- 中英日混排不做字体切换，靠 Noto Sans SC 与文楷自身的多语言字形。

## 布局

- 桌面：76px 图标栏 + 324px 列表 + 纸张编辑区。列表可收起，专注模式下全部隐藏。
- 移动：底部四个入口（今日 / 日历 / 统计 / 我的）；编辑页全屏，工具栏在键盘上方。
- 纸张是「主角」：最大宽度 980px，四周留出桌面底色，形成一张纸放在桌上的感觉。
- 会话状态（编辑中的滚动的、焦点）由 EditorSession 持有，切换视图不丢稿。

## 动效

| 名称 | 时长 | 曲线 | 用途 |
| --- | --- | --- | --- |
| fast | 160ms | easeOutCubic | 悬停、按下 |
| base | 260ms | `Cubic(0.16, 1, 0.3, 1)` | 面板展开、选中 |
| slow | 440ms | easeOutCubic | 页面切换、引导 |
| breathe | 2.4s | easeInOut | 保存状态点 |

原则：

- 动效只解释状态变化，不做装饰性循环。
- 进入用淡入 + 8–14px 上浮；退出更快。
- 选中、悬停使用背景色与 1px 边框，不使用发光。
- 保存状态点会呼吸；保存完成变为静态绿点。

## 组件

- `PaperSurface`：纸面卡片（发丝边 + 极浅阴影 + 纸纹）。
- `SoftIconButton` / `SoftButton`：透明底、悬停纸色、选中朱砂淡底。
- `TagChip`：小号标签，可选中、可删除。
- `Seal`：朱砂印章，应用图标与品牌标识。
- `RollingNumber` / `BreathingDot`：统计与保存反馈。
- `Reveal`：页面入场；`HoverBuilder`：鼠标悬停进度。

## 交互约定

- 所有破坏性操作二次确认，危险按钮使用朱砂。
- 导出前先保存；恢复备份前自动再备份一次。
- AI 默认关闭；结果先预览再写入；不覆盖未确认的文字。
- 空状态永远给出下一步动作（写日记 / 写随笔 / 看模板）。
- 任何页面都能一键回到「今日」。

## 字体

- **Noto Sans SC**：SIL OFL 1.1；从可变字体实例化 Light 300 / Regular 400 / Bold 700，覆盖中英日，保持正文安静、清晰。
- **LXGW WenKai**：SIL OFL 1.1；用于标题、字标与花字，覆盖中文、英文与日文假名。
- **Smiley Sans 得意黑**：SIL OFL 1.1；用于有个性的标题，斜切笔画自带速度感。
- **Source Han Mono 思源等宽**：SIL OFL 1.1；用于代码块、行内代码与等宽排版，中英日字宽一致。
- 以上字体都覆盖中英日常用字符；导出 PDF 时嵌入字体。
